## Условие

В первой части задания я создал матрицу размером `M x N` и заполнил её случайными числами в диапазоне `[10; 50]`.

В третьей части я реализовал клеточный автомат Джона Конвея. Поле состоит из живых и мёртвых клеток, которые обновляются по классическим правилам. Для демонстрации я добавил устойчивые фигуры `Block`, `Beehive`, `Loaf`, `Boat`, планер `Glider`, а также случайную генерацию колонии клеток.

# Задание 2. AES-128 CBC

## Условие

В этом задании я реализовал шифрование и расшифрование текста с помощью алгоритма `AES-128` в режиме `CBC`.

Сначала программа предлагает выбрать, откуда взять текст: ввести его с консоли или прочитать из файла. После этого я генерирую случайный ключ и вектор инициализации `IV`. Ключ записывается в файл `key.txt`, а `IV` записывается в файл `iv.txt`. Затем текст шифруется, зашифрованный результат сохраняется в `encrypted.txt`, а после расшифрования восстановленный текст записывается в `decrypted.txt`.

## Как работает

AES шифрует данные блоками по `16` байт. Каждый блок я перевожу во внутреннюю таблицу `State` размером `4 x 4`. Дальше над ней выполняются раунды преобразований: `SubBytes`, `ShiftRows`, `MixColumns` и `AddRoundKey`.

В режиме `CBC` каждый блок перед шифрованием смешивается с предыдущим зашифрованным блоком через XOR. Для первого блока я использую `IV`. Благодаря этому одинаковые блоки исходного текста после шифрования выглядят по-разному.

## Основные функции

- `generateRandomBytes` — с помощью этой функции я создаю случайный ключ и `IV`.
- `stringToBytes` — с помощью этой функции я перевожу текст в байты.
- `bytesToString` — с помощью этой функции я перевожу байты обратно в текст.
- `expandKey` — с помощью этой функции я создаю раундовые ключи AES.
- `addPadding` — с помощью этой функции я дополняю текст до размера, кратного `16` байтам.
- `encryptCBC` — с помощью этой функции я шифрую текст в режиме CBC.
- `decryptCBC` — с помощью этой функции я расшифровываю текст в режиме CBC.
- `encryptBlock` — с помощью этой функции я шифрую один блок AES.
- `decryptBlock` — с помощью этой функции я расшифровываю один блок AES.
- `bytesToHex` — с помощью этой функции я перевожу байты в HEX-строку.
- `saveBytesToFile` — с помощью этой функции я сохраняю ключ и `IV` в файлы.

## Пример 1. Ввод текста с консоли

### Ввод

```text
1
Hello AES
```

### Результат

```text
Сгенерированный ключ: ...
Вектор инициализации IV: ...
Зашифрованный текст HEX: ...
Расшифрованный текст: Hello AES
```

## Пример 2. Чтение текста из файла

### Ввод

```text
2
input.txt
```

### Результат

```text
Зашифрованный текст записывается в encrypted.txt
Расшифрованный текст записывается в decrypted.txt
```

# Задание 3. Метод Гаусса

## Условие

В этом задании я реализовал решение системы линейных уравнений методом Гаусса. Сначала пользователь вводит параметры `M`, `N` и `P`, после чего программа подставляет их в матрицу коэффициентов и столбец свободных членов.

Сначала я вывожу исходную систему. Затем выполняю прямой ход метода Гаусса: матрица постепенно приводится к верхнетреугольному виду. После этого запускается обратный ход, где программа находит значения неизвестных.

Также я добавил вычисление определителя матрицы. Для этого после прямого хода перемножаются элементы главной диагонали. Если во время решения строки менялись местами, программа отдельно учитывает знак определителя.

## Основные функции

- `createMatrix` — с помощью этой функции я создаю квадратную матрицу коэффициентов.
- `createMassive` — с помощью этой функции я создаю массив для свободных членов или корней.
- `deleteMatrix` — с помощью этой функции я освобождаю память, выделенную под матрицу.
- `zapolnitSistem` — с помощью этой функции я заполняю систему коэффициентами и свободными членами.
- `printSistem` — с помощью этой функции я вывожу систему на экран.
- `findGlavStroku` — с помощью этой функции я ищу строку с главным элементом в текущем столбце.
- `swapStroki` — с помощью этой функции я меняю две строки местами.
- `pryamoiHod` — с помощью этой функции я выполняю прямой ход метода Гаусса.
- `obratniyHod` — с помощью этой функции я выполняю обратный ход и нахожу корни.
- `printKorni` — с помощью этой функции я вывожу найденные корни.
- `gauss` — с помощью этой функции я запускаю всё решение системы.

# Задание 4. Матрица из 0 и 1

## Условие

В этом задании я работал с прямоугольным щитом размером `N x M`. В каждой клетке лежит монета: `0` означает орёл, а `1` означает решку. За один ход можно выбрать любые две соседние по стороне монеты и перевернуть их одновременно.

Мне нужно было определить минимальное количество таких ходов, за которое щит можно привести к одному из нужных рисунков: верхняя половина заполнена одним значением, а нижняя половина другим.

Я рассматриваю два варианта итоговой матрицы:

- сверху `0`, снизу `1`;
- сверху `1`, снизу `0`.

После этого программа выбирает вариант, для которого нужно меньше ходов. В коде я считаю, какие клетки отличаются от нужного рисунка, а затем подбираю пары таких клеток с минимальным расстоянием между ними.

## Основные функции

- `createMatrix` — с помощью этой функции я создаю динамическую матрицу.
- `deleteMatrix` — с помощью этой функции я освобождаю память, выделенную под матрицу.
- `zapolitMatrix` — с помощью этой функции я считываю матрицу из `0` и `1`.
- `printMatrix` — с помощью этой функции я вывожу матрицу на экран.
- `rastMinHodov` — с помощью этой функции я считаю минимальное число соседних переходов между двумя клетками.
- `findNepravilnieKletki` — с помощью этой функции я нахожу клетки, которые стоят не на своих местах.
- `podborPar` — с помощью этой функции я подбираю пары неправильных клеток с минимальной суммой ходов.
- `minHodovRisunka` — с помощью этой функции я считаю минимальное количество ходов для одного варианта рисунка.
- `minHodovDoPolovini` — с помощью этой функции я выбираю минимальный результат из двух вариантов.
- `findBestVerh` — с помощью этой функции я определяю, какое значение выгоднее поставить сверху.
- `printItogMatrix` — с помощью этой функции я вывожу итоговую матрицу.
